# Spoken Hindi style
- Write for the ear: short sentences (<= 15 words), one idea each. Address the child as "आप"/"बच्चो", warm and encouraging.
- Plain everyday Hindi. Keep the English science term in brackets the first time, e.g. "पदार्थ (material)", then use the Hindi word.
- No long Sanskritised words when a common one exists. Avoid "अतः", "तथापि", "यथा".
- Write numbers and units as they are spoken ("दस ग्राम"), no symbols the TTS cannot read.
- Ask a question, pause (a short line), then answer it, like a teacher in a room.
- Never talk down to the student. Praise effort, not intelligence.
